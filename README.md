# About me

Личная страница Eshpolot с присланным изображением. Кнопки соцсетей пока отключены; ссылки можно добавить после того, как владелец их предоставит.

Оформление основано на примере [5ekastanx/About-Me](https://github.com/5ekastanx/About-Me).

Откройте `index.html` в браузере или запустите `python3 -m http.server 8000`.
