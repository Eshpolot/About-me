# About me

Компактная личная страница со ссылками на соцсети, в стиле страницы-визитки. Сайт статический и не требует сборки.

Откройте `index.html` в браузере или запустите локальный сервер:

```sh
python3 -m http.server 8000
```

Ссылки на остальные соцсети и фотографию можно добавить позже. Пока активна только ссылка на GitHub.
